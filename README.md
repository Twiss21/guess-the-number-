# Guess the Number

A modern Guess the Number game built with HTML, CSS, and vanilla JavaScript.

## Try It Online

After enabling **GitHub Pages**, the app will be available at:

```text
https://TVE-JMENO.github.io/TVE-REPOSITORY/
```

In GitHub:

1. Open the repository and go to `Settings` > `Pages`.
2. Select `Deploy from a branch` as the source.
3. Select the `main` branch and the `/ (root)` folder.
4. Save the settings and open the generated link.

## How to Download and Open the Game

1. Open the GitHub repository.
2. Click the green `Code` button.
3. Select `Download ZIP`.
4. Open the ZIP file from your Downloads folder.
5. Extract the ZIP file.
6. Open the extracted folder.
7. Double-click `index.html` to start the game in your browser.

The app can also be installed as a PWA. Open the online version in Chrome and use the browser install option or the `Install app` button.

The project contains:

- `index.html`
- `style.css`
- `script.js`
- `manifest.json`
- `service-worker.js`
- `icon.svg`

## Features

- Random number in a customizable range from 1 to 5000
- Higher / lower hints
- Automatic new round after a win
- Score saved in `localStorage`
- Attempt counter
- Guess submission with the `Enter` key
- Responsive design
- App installation and offline support
